# 🚀 DigiTools - AI Tools Marketplace

A modern React-based web application where users can explore digital tools, add them to cart, and manage purchases easily.

## 📌 Features

* 🧠 Explore AI-powered tools
* 🛒 Add items to cart (No duplicate items)
* 🔄 Dynamic cart update in Navbar
* 📊 Cart total calculation
* ❌ Remove items from cart
* 💳 Checkout functionality (Toast notification)
* 🔔 Toast notifications using React Toastify
* 📱 Fully responsive design (Mobile, Tablet, Desktop)
* 🎨 Clean UI with Tailwind CSS & DaisyUI

---

## 🧩 Tech Stack

* ⚛️ React.js
* 🎨 Tailwind CSS
* 🌼 DaisyUI
* 🔔 React Toastify
* 🧱 Lucide Icons

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

```bash
# Clone the repository
git clone https://github.com/your-username/digitools.git

# Navigate into the project
cd digitools

# Install dependencies
npm install

# Run the development server
npm run dev
```

## 🛒 How It Works

* Click on any tool → added to cart
* Cart icon in Navbar updates dynamically
* Duplicate items are prevented
* Switch between **Products** and **Cart** tabs
* Remove items or checkout easily
